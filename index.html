🎓 What Is Base64 — and What It Is NOT

An encoding, not a lock. Base64 rewrites binary data using 64 safe characters (A–Z, a–z, 0–9, +, /) so it can travel through systems designed for text — email, URLs, JSON, HTML. Every 3 bytes become 4 characters, so the output is about 33% larger.
Where you see it: email attachments (MIME), images embedded in web pages (data:image/png;base64,…), JSON Web Tokens, basic-auth headers, and API payloads that must carry files as text.
⚠️ Security note: Base64 is NOT encryption and NOT hashing. Anyone can decode it instantly — including with this page. Never treat Base64 as a way to hide passwords, tokens or secrets. Attackers also use Base64 to disguise malicious payloads, which is exactly why defenders learn to decode and inspect it.
